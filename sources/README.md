# Литература курса

Все оригиналы лежат здесь, по полкам (`role` в `course/content/sources.json`). Имя файла: **Автор — Название**.

Пути в каталоге курса — относительно папки `course/`, например `../sources/core/Моргунов Е. П. — PostgreSQL. Основы языка SQL.pdf`.
