### ANSI SQL и диалекты

**Стандарт SQL** задаёт общий синтаксис. **Диалект** — реализация конкретной СУБД с расширениями.

### PostgreSQL vs T-SQL

| Особенность | PostgreSQL | T-SQL (SQL Server) |
|-------------|------------|-------------------|
| LIMIT | LIMIT n | TOP n / OFFSET-FETCH |
| Строки | \|\|, concat() | + (устар.), concat |
| Boolean | TRUE/FALSE | bit |
| Sequences | SERIAL, IDENTITY | IDENTITY |

### SQLite vs PostgreSQL (книга Шилдса)

«SQL: быстрое погружение» написана на **SQLite**. В этом курсе практика — PostgreSQL. Не переносите примеры книги буквально:

| Тема | SQLite (часто в книге) | PostgreSQL в курсе |
|------|------------------------|--------------------|
| Регистр в LIKE | часто без регистра | `LIKE` чувствителен; без регистра — `ILIKE` |
| RIGHT / FULL JOIN | в старых версиях нет | есть; RIGHT можно переписать как LEFT |
| Дата без времени | `DATE(col)`, `strftime` | `col::date`, `EXTRACT`, `DATE_TRUNC` |
| Среда | DB Browser, файл `.db` | сервер PostgreSQL, `psql` / pgAdmin |

### Выбор источника

Для PostgreSQL — Morgunov. Для T-SQL — Ben-Gan, Pro T-SQL. При переносе запросов проверяйте типы, функции и системные каталоги.

### Миграция и расширения

IDENTITY→SERIAL, datetime→timestamp. JSONB и GIN — сила диалекта PostgreSQL. T-SQL актуален для SQL Server (уроки p9-l07–08).
