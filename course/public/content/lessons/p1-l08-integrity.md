### Виды целостности

**Сущностная** — PK уникален, NOT NULL. **Ссылочная** — FK указывает на существующий PK. **Доменная** — значение из допустимого множества (тип, CHECK).

### Примеры нарушений

- Две строки student с одним student_id — нарушение сущностной.
- group_id = 999 без строки в s_group — ссылочная.
- score = 150 при CHECK (0–100) — доменная.

### DDL PostgreSQL

```sql
CREATE TABLE grade (
  student_id INT REFERENCES student(student_id),
  score INT CHECK (score BETWEEN 0 AND 100)
);
```

### Триггеры и бизнес-правила

Сложные правила («студент не может сдать экзамен дважды в один день») — CHECK, UNIQUE или триггеры. Целостность защищает данные от ошибок приложений.

### PostgreSQL и правила

DEFERRABLE FK помогает при загрузке. Межтабличные ASSERTION в PG нет — триггеры. COMMENT ON документирует бизнес-правила grade.
