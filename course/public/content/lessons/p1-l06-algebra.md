### Операции реляционной алгебры

**Выборка σ** — фильтр строк: σ_{score≥90}(grade). **Проекция π** — выбор столбцов. **Соединение ⋈** — комбинация по условию. **Объединение ∪**, **разность −**, **декартово произведение ×**.

### Пример

«Студенты группы ИВТ-21 с оценкой > 80»:

1. σ_{name='ИВТ-21'}(s_group)
2. student ⋈ s_group по group_id
3. ⋈ grade по student_id, σ_{score>80}
4. π_{full_name}

### SQL-эквивалент

```sql
SELECT s.full_name FROM student s
JOIN s_group g ON s.group_id = g.group_id
JOIN grade gr ON gr.student_id = s.student_id
WHERE g.name = 'ИВТ-21' AND gr.score > 80;
```

Результат каждой операции — отношение; операции композируются.
