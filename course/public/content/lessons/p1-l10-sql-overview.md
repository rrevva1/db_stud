### Категории SQL

**DDL** (Data Definition Language) — CREATE, ALTER, DROP: структура. **DML** — SELECT, INSERT, UPDATE, DELETE: данные. **DCL** — GRANT, REVOKE: доступ. **TCL** — BEGIN, COMMIT, ROLLBACK: транзакции.

### Жизненный цикл данных

1. CREATE TABLE — определение схемы.
2. INSERT — загрузка.
3. SELECT — выборка и отчёты.
4. UPDATE/DELETE — изменения.
5. ALTER — эволюция схемы.
6. DROP — удаление объектов.

### Стандарт и диалекты

ANSI/ISO SQL — общая основа. PostgreSQL, Oracle, SQL Server добавляют расширения. Курс опирается на PostgreSQL с указанием отличий где нужно.

### Стандарт и psql

Придерживайтесь SQL-ядра для переносимости. \dt, \d — команды psql, не SQL. Часть 3: DDL → DML → SELECT → JOIN → транзакции.
