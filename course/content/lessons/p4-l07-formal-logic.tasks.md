## Практика (теория + разбор)

Этот урок преимущественно теоретический. Выполните письменные задания; SQL — по желанию для иллюстрации.

### Задание 1. Алгебра → SQL

Дано: R(A,B), S(B,C). Запишите реляционное выражение π_{A,C}(R ⋈ S) и эквивалентный SQL.

### Задание 2. Bag vs Set

Создайте таблицу без PK, вставьте дубликаты. Покажите разницу `SELECT x` и `SELECT DISTINCT x`. Объясните риск `UPDATE ... WHERE x = 1`.

### Задание 3. NULL и NOT IN

Приведите минимальный пример, где `NOT IN (1, NULL)` не возвращает ожидаемых строк. Предложите исправление через NOT EXISTS.

### Задание 4. Антипаттерн

Найдите в учебных скриптах (или придумайте) запрос с неявным JOIN. Перепишите с явным INNER JOIN и прокомментируйте.

### Задание 5. Эссе (½ страницы)

«Почему SQL успешен, несмотря на расхождение с реляционной теорией?» — 3 аргумента.
