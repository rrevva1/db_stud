### Установка PostgreSQL на Windows

Для практики необходима локальная установка PostgreSQL. Ниже — пошаговая инструкция для **Windows 10/11**.

### Шаг 1. Скачивание

1. Перейдите на https://www.postgresql.org/download/windows/
2. Выберите установщик **EDB PostgreSQL** (версия 16 или 17).
3. Скачайте инсталлятор для Windows x86-64.

### Шаг 2. Установка

1. Запустите `.exe` от имени администратора.
2. Каталог установки: `C:\Program Files\PostgreSQL\17`.
3. Компоненты: **PostgreSQL Server**, **pgAdmin 4**, **Command Line Tools**.
4. Задайте пароль суперпользователя **postgres**.
5. Порт: **5432**. Locale: **Russian, Russia** или по умолчанию.

### Шаг 3. Проверка службы

Откройте `services.msc`, найдите `postgresql-x64-17`, убедитесь, что статус — **Работает**.

### Шаг 4. Клиент psql

Добавьте в PATH: `C:\Program Files\PostgreSQL\17\bin`. Проверьте: `psql --version`.

### Шаг 5. Первое подключение

```bash
psql -U postgres -h localhost -p 5432
```

### Шаг 6. Учебная база

```sql
CREATE USER dbstud WITH PASSWORD 'dbstud2024';
CREATE DATABASE dbstud OWNER dbstud;
GRANT ALL PRIVILEGES ON DATABASE dbstud TO dbstud;
\c dbstud dbstud
SELECT version();
```

### Типичные проблемы

- **Порт 5432 занят** — `netstat -ano | findstr 5432`, смените порт.
- **psql не найден** — добавьте `bin` в PATH.
- **Ошибка аутентификации** — проверьте `pg_hba.conf`.

### pgAdmin и безопасность

Используйте pgAdmin для просмотра схемы и psql для скриптов. Пароль postgres храните отдельно от учебного пользователя dbstud. Успешная установка: служба работает, psql подключается, база dbstud создана.
