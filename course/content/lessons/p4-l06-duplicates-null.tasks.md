## Практика PostgreSQL

### Задание 1. NOT IN ловушка

Создайте таблицу с `department_id`, включая NULL. Покажите, что `WHERE id NOT IN (1, 2, NULL)` не возвращает строк. Исправьте через `NOT EXISTS`.

### Задание 2. Дубликаты email

Найдите дубликаты `email` в таблице пользователей. Удалите лишние, оставив строку с минимальным `id`.

### Задание 3. DISTINCT ON

Для каждого `passenger_id` оставьте последнее бронирование (`ORDER BY booked_at DESC`) через `DISTINCT ON`.

### Задание 4. NULL в отчёте

Постройте отчёт: количество студентов с телефоном / без (`COUNT(phone)` vs `COUNT(*)`), средний балл с `COALESCE` для пустых групп.

### Самопроверка

- [ ] Используете `IS NULL`, не `= NULL`
- [ ] NOT IN — список без NULL или альтернатива
- [ ] После удаления дубликатов HAVING COUNT > 1 пуст
