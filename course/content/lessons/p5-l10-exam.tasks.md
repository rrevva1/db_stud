## Практика PostgreSQL — итоговый контроль

Время: 120 минут. Схемы: **университет**, **авиакомпания**.

### Задача 1. Индексы

Для нагрузки «поиск бронирований по flight_id + booked_at + status» спроектируйте индекс. Обоснуйте порядок столбцов. EXPLAIN до/после.

### Задача 2. Специальный индекс

Полнотекстовый или GIN на jsonb payload событий — один запрос с EXPLAIN ANALYZE.

### Задача 3. План запроса

Тяжёлый JOIN 3 таблиц — разберите план, найдите узкое место, предложите fix (индекс или rewrite).

### Задача 4. Секционирование

Таблица логов по RANGE (месяц). Покажите pruning на EXPLAIN.

### Задача 5. VACUUM

Симулируйте bloat (массовый UPDATE), покажите n_dead_tup, выполните VACUUM.

### Задача 6. Безопасный dynamic SQL

Функция отчёта с параметрами date_from, date_to, optional status — whitelist, USING, без конкатенации.

### Самопроверка

- [ ] Все EXPLAIN сохранены в комментариях
- [ ] Индексы не избыточны (обоснование)
- [ ] Dynamic SQL проходит «тест injection» на тестовой БД
