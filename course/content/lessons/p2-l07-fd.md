### Функциональные зависимости

Обозначение **X → Y**: для каждого X значение Y однозначно определено.

Пример: student_id → full_name. group_id → group_name, course_year.

### Замыкание

F⁺ — все FD, выводимые из F аксиомами Армстронга (рефлексивность, дополнение, транзитивность).

### Ключи через FD

Кандидатный ключ K: K → все атрибуты и ни один подмножество K этого не делает. Для grade: {student_id, course_id} → score, exam_date.

### Транзитивность

student_id→group_id→faculty мотивирует 3NF. Проверяйте декomпозицию без потерь: R = R1 ⋈ R2 без лишних строк.
