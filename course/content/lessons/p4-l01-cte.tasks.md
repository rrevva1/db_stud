## Практика PostgreSQL

Используйте учебную схему **университет** (`student`, `s_group`, `performance`) или создайте мини-схему сотрудников.

### Задание 1. Простой CTE

Напишите запрос: средний балл по каждой группе, затем список студентов с баллом выше среднего **своей** группы. Используйте `WITH group_avg AS (...)`.

### Задание 2. Цепочка CTE

Три CTE подряд: (1) активные студенты, (2) их оценки за последний семестр, (3) итоговый рейтинг. Финальный `SELECT` — топ-5 студентов.

### Задание 3. Рекурсивный CTE

Таблица `employee(id, name, manager_id)`. Выведите всех подчинённых заданного руководителя с полем `level` (глубина вложенности).

```sql
-- подготовка (при необходимости)
CREATE TABLE IF NOT EXISTS employee (
    id SERIAL PRIMARY KEY,
    name TEXT NOT NULL,
    manager_id INT REFERENCES employee(id)
);
```

### Задание 4. Защита от циклов

В графе рёбер `(from_id, to_id)` найдите все узлы, достижимые из узла 1. Используйте `CYCLE` (PostgreSQL 14+) или массив посещённых узлов.
