### Реляционное исчисление

**Исчисление кортежей (TRC)**: { t | P(t) } — множество кортежей t, для которых истинно предикат P.

Пример: { s | ∃g (s.group_id = g.group_id ∧ g.name = 'ИВТ-21') } — студенты группы ИВТ-21.

**Исчисление доменов (DRC)** — переменные над доменами атрибутов.

### Связь с SQL

SQL WHERE близок к предикату исчисления. SELECT-FROM-WHERE декларативен: описываем *что* нужно, не *как* перебирать.

### Алгебра и исчисление

Теорема Кодда: безопасные выражения TRC и DRC эквивалентны по выразительности реляционной алгебре. Оптimizer PostgreSQL преобразует SQL в алгебраические планы.

### Кванторы и SQL

«Сдавшие все курсы» — задача на ∀ через NOT EXISTS. Исчисление объясняет декларативность SELECT-WHERE перед частью 3.
