### Краткая теория

**SELECT** — основная команда SQL для выборки данных. Результат запроса — **виртуальная таблица** (набор строк и столбцов).

#### Перед тем как писать запрос

Ответьте на пять вопросов — и клаузы SELECT почти соберутся сами:

1. Из какой **базы** и схемы берём данные?
2. Из какой **таблицы** (или нескольких)?
3. Какие **столбцы** нужны в результате — не `*` без нужды?
4. Какие **строки** отфильтровать, как **упорядочить**, сколько показать?
5. Как сформулировать задачу **одной фразой** на естественном языке?

Пример: «Показать 10 студентов третьего курса по алфавиту фамилии» → `FROM student` + фильтр курса + `ORDER BY last_name` + `LIMIT 10`.

#### Комментарии в запросе

```sql
-- однострочный комментарий: зачем этот запрос
SELECT last_name, first_name
FROM student;  /* блок: список без оценок */
```

Это не `COMMENT ON TABLE` (комментарий к объекту схемы), а пометки в тексте SQL.

Соглашение курса: **один оператор (SELECT / FROM / WHERE / …) на строку**; в SELECT перечисляйте столбцы, а не `*`, кроме разведки данных.

#### Базовый синтаксис

```sql
SELECT столбец1, столбец2
FROM   таблица;
```

Выбор всех столбцов (избегайте в production-коде):

```sql
SELECT * FROM student;
```

#### Псевдонимы (алиасы)

```sql
SELECT last_name AS фамилия,
       first_name "Имя",
       birth_date AS dob
FROM student;
```

#### DISTINCT — уникальные строки

```sql
SELECT DISTINCT course_num FROM s_group;
SELECT DISTINCT last_name, first_name FROM student;
```

`DISTINCT` применяется ко **всей** комбинации столбцов.

#### LIMIT и OFFSET — Top-N и страницы

`LIMIT` применяется **после** `ORDER BY`. Два разных смысла:

```sql
-- Top-N: десять самых молодых
SELECT last_name, first_name, birth_date
FROM student
ORDER BY birth_date DESC
LIMIT 10;

-- страница: записи 21–30 по фамилии
SELECT last_name, first_name
FROM student
ORDER BY last_name
LIMIT 10 OFFSET 20;
```

Без `ORDER BY` набор из `LIMIT` не определён: СУБД может вернуть любые n строк.

#### Выражения в SELECT

```sql
SELECT last_name,
       EXTRACT(YEAR FROM birth_date) AS birth_year,
       UPPER(first_name) AS name_upper
FROM student;
```

#### Порядок выполнения (упрощённо)

1. FROM → 2. WHERE → 3. GROUP BY → 4. HAVING → 5. SELECT → 6. ORDER BY → 7. LIMIT

На этом уроке — шаги FROM, SELECT, DISTINCT, LIMIT/OFFSET.
