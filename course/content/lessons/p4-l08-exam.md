## Контроль: продвинутый SQL

**Часть:** Продвинутый SQL · **Модуль:** Расширенные возможности SQL

Практика: **PostgreSQL** (psql или pgAdmin).

### Цели урока

- Решить задачи на CTE и оконные функции
- Построить сводный отчёт (pivot)
- Обосновать выбор конструкции SQL

### Краткая теория

Итоговый контроль по части 4 охватывает:

1. **CTE** — линейные и рекурсивные запросы, читаемая декомposition.
2. **Оконные функции** — ранжирование, LAG/LEAD, скользящие агрегаты.
3. **LATERAL и unnest** — TOP-N на группу, развёртывание массивов/JSON.
4. **Pivot** — FILTER, CASE, crosstab.
5. **Представления** — updatable views, INSTEAD OF, CHECK OPTION.
6. **NULL и дубликаты** — трёхзначная логика, NOT IN, DISTINCT ON.
7. **Теория** — bag vs set, связь с алгеброй.

#### Критерии выбора конструкции

| Задача | Рекомендация |
|--------|--------------|
| Иерархия | RECURSIVE CTE |
| Рейтинг в группе | ROW_NUMBER + PARTITION BY или LATERAL |
| Сводная таблица | FILTER / crosstab |
| Обновление через JOIN-VIEW | INSTEAD OF trigger |
| Дубликаты по ключу | ROW_NUMBER + DELETE или DISTINCT ON |

#### Типичные ошибки на контроле

- Забытый ORDER BY в оконной функции
- Бесконечная рекурсия без условия остановки
- NOT IN с NULL в подзапросе
- crosstab без совпадения типов столбцов в AS ct(...)
