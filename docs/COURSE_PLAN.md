# План курса «Базы данных: от проектирования до SQL»

Локальный веб-курс в формате Stepik: теория → источники (PDF) → тест → практика.

## Принципы

- **Одна тема = один урок:** теория → блок «Источники» → тест → практика.
- **Ядро:** Лекция 1 → Моргунов + Практикум (PostgreSQL) → Новиков.
- **Практика SQL только на PostgreSQL.** T-SQL / MongoDB / Cypher — отдельные ветки с пометкой диалекта.
- **Авторское право:** текст книг не копируется; только пересказ и ссылка на главу PDF.
- **Источники читают по очереди:** в уроке и в блоке «Источники» — 1-я очередь, 2-я, затем «далее по желанию». Ядро (Моргунов, Новиков, Дейт, Практикум) раньше педагогики (Бейли, Шилдс).
- **Предметная область:** схема «университет» (student / s_group / performance) + проект «авиакомпания».
- **Тесты проверяют понимание, а не угадывание.** Дистракторы из той же темы и похожей длины; правильный ответ не всегда первый; запрещены мусорные варианты (`HTML`, `цвет волос`, случайный `VACUUM`). Стем — ситуация или фрагмент SQL. В SQL-уроках есть вопросы «что вернёт запрос» на мини-выборке. Экзамены — 12 вопросов, порог 75%. Варианты перемешиваются в интерфейсе.

## Запуск

### Без Node.js (статический режим)

Откройте `course/index.html` в браузере через локальный HTTP-сервер (fetch не работает с `file://`):

```powershell
cd e:\Projects\db_stud\course
python -m http.server 8080
# или: npx serve . -p 8080
```

Откройте http://localhost:8080

### С Node.js (React + Vite)

```powershell
cd e:\Projects\db_stud\course
npm install
npm run dev
```
